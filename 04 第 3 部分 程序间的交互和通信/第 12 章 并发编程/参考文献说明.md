# 参考文献说明

[返回章节目录](./%E7%AC%AC12%E7%AB%A0%20%E5%B9%B6%E5%8F%91%E7%BC%96%E7%A8%8B.md)

信号量操作是 Dijkstra 提出的 [\[31\]](#ref-31)。进度图的概念是 Coffman [\[23\]](#ref-23) 提出的，后来由 Carson 和 Reynolds [\[16\]](#ref-16) 形式化的。Courtois 等人 [\[25\]](#ref-25) 提出了读者-写者问题。操作系统教科书更详细地描述了经典的同步问题，例如哲学家进餐问题、打瞌睡的理发师问题和吸烟者问题 \[[102](#ref-102), [106](#ref-106), [113](#ref-113)\]。Butenhof 的书 [\[15\]](#ref-15) 对 Posix 线程接口有全面的描述。Birrell [\[7\]](#ref-7) 的论文对线程编程以及线程编程中容易遇到的问题做了很好的介绍。Reinders 的书 [\[90\]](#ref-90) 描述了 C/C++ 库，简化了线程化程序的设计和实现。有一些课本讲述了多核系统上并行编程的基础知识 \[[47](#ref-47), [71](#ref-71)\]。Pugh 描述了 Java 线程通过内存进行交互的方式的缺陷，并提出了替代的内存模型 [\[88\]](#ref-88)。Gustafson 提出了替代强扩展的弱扩展加速模型 [\[43\]](#ref-43)。
