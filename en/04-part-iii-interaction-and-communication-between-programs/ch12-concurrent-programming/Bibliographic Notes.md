# Bibliographic Notes

[Back to Chapter Contents](./Chapter%2012%20Concurrent%20Programming.md)

Semaphore operations were introduced by Dijkstra [\[31\]](../../05-appendix-and-references/References.md#31). The progress graph concept was introduced by Coffman [\[23\]](../../05-appendix-and-references/References.md#23) and later formalized by Carson and Reynolds [\[16\]](../../05-appendix-and-references/References.md#16). The readers-writers problem was introduced by Courtois et al. [\[25\]](../../05-appendix-and-references/References.md#25). Operating systems texts describe classical synchronization problems such as the dining philosophers, sleeping barber, and cigarette smokers problems in more detail [\[102\]](../../05-appendix-and-references/References.md#102), [\[106\]](../../05-appendix-and-references/References.md#106), [\[113\]](../../05-appendix-and-references/References.md#113). The book by Butenhof [\[15\]](../../05-appendix-and-references/References.md#15) is a comprehensive description of the Posix threads interface. The paper by Birrell [\[7\]](../../05-appendix-and-references/References.md#7) is an excellent introduction to threads programming and its pitfalls. The book by Reinders [\[90\]](../../05-appendix-and-references/References.md#90) describes a C/C++ library that simplifies the design and implementation of threaded programs. Several texts cover the fundamentals of parallel programming on multi-core systems [\[47\]](../../05-appendix-and-references/References.md#47), [\[71\]](../../05-appendix-and-references/References.md#71). Pugh identifies weaknesses with the way that Java threads interact through memory and proposes replacement memory models [\[88\]](../../05-appendix-and-references/References.md#88). Gustafson proposed the weak-scaling speedup model [\[43\]](../../05-appendix-and-references/References.md#43) as an alternative to strong scaling.
