# Bibliographic Notes

[Back to Chapter Contents](./Chapter%204%20Processor%20Architecture.md)

For those interested in learning more about logic design, the Katz and Borriello logic design textbook [\[58\]](#ref-58) is a standard introductory text, emphasizing the use of hardware description languages. Hennessy and Patterson's computer architecture textbook [\[46\]](#ref-46) provides extensive coverage of processor design, including both simple pipelines, such as the one we have presented here, and advanced processors that execute more instructions in parallel. Shriver and Smith [\[101\]](#ref-101) give a very thorough presentation of an Intel-compatible x86-64 processor manufactured by AMD.
