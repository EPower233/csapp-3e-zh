# Bibliographic Notes

[Back to Chapter Contents](./Chapter%206%20The%20Memory%20Hierarchy.md)

Memory and disk technologies change rapidly. In our experience, the best sources of technical information are the Web pages maintained by the manufacturers. Companies such as Micron, Toshiba, and Samsung provide a wealth of current technical information on memory devices. The pages for Seagate and Western Digital provide similarly useful information about disks.

Textbooks on circuit and logic design provide detailed information about memory technology \[[58](./../../05-appendix-and-references/References.md#ref-58), [89](./../../05-appendix-and-references/References.md#ref-89)\]. IEEE Spectrum published a series of survey articles on DRAM [\[55\]](./../../05-appendix-and-references/References.md#ref-55). The International Symposiums on Computer Architecture (ISCA) and High Performance Computer Architecture (HPCA) are common forums for characterizations of DRAM memory performance \[[28](./../../05-appendix-and-references/References.md#ref-28), [29](./../../05-appendix-and-references/References.md#ref-29), [18](./../../05-appendix-and-references/References.md#ref-18)\].

Wilkes wrote the first paper on cache memories [\[117\]](./../../05-appendix-and-references/References.md#ref-117). Smith wrote a classic survey [\[104\]](./../../05-appendix-and-references/References.md#ref-104). Przybylski wrote an authoritative book on cache design [\[86\]](./../../05-appendix-and-references/References.md#ref-86). Hennessy and Patterson provide a comprehensive discussion of cache design issues [\[46\]](./../../05-appendix-and-references/References.md#ref-46). Levinthal wrote a comprehensive performance guide for the Intel Core i7 [\[70\]](./../../05-appendix-and-references/References.md#ref-70).

Stricker introduced the idea of the memory mountain as a comprehensive characterization of the memory system in [\[112\]](./../../05-appendix-and-references/References.md#ref-112) and suggested the term "memory mountain" informally in later presentations of the work. Compiler researchers work to increase locality by automatically performing the kinds of manual code transformations we discussed in [Section 6.6](6.6%20Putting%20It%20Together%EF%BC%9A%20The%20Impact%20of%20Caches%20on%20Program%20Performance.md) \[[22](./../../05-appendix-and-references/References.md#ref-22), [32](./../../05-appendix-and-references/References.md#ref-32), [66](./../../05-appendix-and-references/References.md#ref-66), [72](./../../05-appendix-and-references/References.md#ref-72), [79](./../../05-appendix-and-references/References.md#ref-79), [87](./../../05-appendix-and-references/References.md#ref-87), [119](./../../05-appendix-and-references/References.md#ref-119)\]. Carter and colleagues have proposed a cache-aware memory controller [\[17\]](./../../05-appendix-and-references/References.md#ref-17). Other researchers have developed cache-oblivious algorithms that are designed to run well without any explicit knowledge of the structure of the underlying cache memory \[[30](./../../05-appendix-and-references/References.md#ref-30), [38](./../../05-appendix-and-references/References.md#ref-38), [39](./../../05-appendix-and-references/References.md#ref-39), [9](./../../05-appendix-and-references/References.md#ref-9)\].

There is a large body of literature on building and using disk storage. Many storage researchers look for ways to aggregate individual disks into larger, more robust, and more secure storage pools \[[20](./../../05-appendix-and-references/References.md#ref-20), [40](./../../05-appendix-and-references/References.md#ref-40), [41](./../../05-appendix-and-references/References.md#ref-41), [83](./../../05-appendix-and-references/References.md#ref-83), [121](./../../05-appendix-and-references/References.md#ref-121)\]. Others look for ways to use caches and locality to improve the performance of disk accesses \[[12](./../../05-appendix-and-references/References.md#ref-12), [21](./../../05-appendix-and-references/References.md#ref-21)\]. Systems such as Exokernel provide increased user-level control of disk and memory resources [\[57\]](./../../05-appendix-and-references/References.md#ref-57). Systems such as the Andrew File System [\[78\]](./../../05-appendix-and-references/References.md#ref-78) and Coda [\[94\]](./../../05-appendix-and-references/References.md#ref-94) extend the memory hierarchy across computer networks and mobile notebook computers. Schindler and Ganger developed an interesting tool that automatically characterizes the geometry and performance of SCSI disk drives [\[95\]](./../../05-appendix-and-references/References.md#ref-95). Researchers have investigated techniques for building and using flash-based SSDs \[[8](./../../05-appendix-and-references/References.md#ref-8), [81](./../../05-appendix-and-references/References.md#ref-81)\].
