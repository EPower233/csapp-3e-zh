# Bibliographic Notes

[Back to Chapter Contents](./Chapter%202%20Representing%20and%20Manipulating%20Information.md)

Reference books on C \[[45](./../../05-appendix-and-references/References.md#ref-45), [61](./../../05-appendix-and-references/References.md#ref-61)\] discuss properties of the different data types and operations. Of these two, only Steele and Harbison [\[45\]](./../../05-appendix-and-references/References.md#ref-45) cover the newer features found in ISO C99. There do not yet seem to be any books that cover the features found in ISO C11. The C standards do not specify details such as precise word sizes or numeric encodings. Such details are intentionally omitted to make it possible to implement C on a wide range of different machines. Several books have been written giving advice to C programmers \[[59](./../../05-appendix-and-references/References.md#ref-59), [74](./../../05-appendix-and-references/References.md#ref-74)\] that warn about problems with overflow, implicit casting to unsigned, and some of the other pitfalls we have covered in this chapter. These books also provide helpful advice on variable naming, coding styles, and code testing. Seacord's book on security issues in C and C++ programs [\[97\]](./../../05-appendix-and-references/References.md#ref-97) combines information about C programs, how they are compiled and executed, and how vulnerabilities may arise. Books on Java (we recommend the one coauthored by James Gosling, the creator of the language [\[5\]](./../../05-appendix-and-references/References.md#ref-5)) describe the data formats and arithmetic operations supported by Java.

Most books on logic design \[[58](./../../05-appendix-and-references/References.md#ref-58), [116](./../../05-appendix-and-references/References.md#ref-116)\] have a section on encodings and arithmetic operations. Such books describe different ways of implementing arithmetic circuits. Overton's book on IEEE floating point [\[82\]](./../../05-appendix-and-references/References.md#ref-82) provides a detailed description of the format as well as the properties from the perspective of a numerical applications programmer.
