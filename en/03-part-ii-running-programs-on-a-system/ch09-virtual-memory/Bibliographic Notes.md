# Bibliographic Notes

[Back to Chapter Contents](./Chapter%209%20Virtual%20Memory.md)

Kilburn and his colleagues published the first description of virtual memory [\[63\]](../../05-appendix-and-references/References.md#ref-63). Architecture texts contain additional details about the hardware's role in virtual memory [\[46\]](../../05-appendix-and-references/References.md#ref-46). Operating systems texts contain additional information about the operating system's role [\[102](../../05-appendix-and-references/References.md#ref-102), [106](../../05-appendix-and-references/References.md#ref-106), [113\]](../../05-appendix-and-references/References.md#ref-113). Bovet and Cesati [\[11\]](../../05-appendix-and-references/References.md#ref-11) give a detailed description of the Linux virtual memory system. Intel Corporation provides detailed documentation on 32-bit and 64-bit address translation on IA processors [\[52\]](../../05-appendix-and-references/References.md#ref-52).

Knuth wrote the classic work on storage allocation in 1968 [\[64\]](../../05-appendix-and-references/References.md#ref-64). Since that time, there has been a tremendous amount of work in the area. Wilson, Johnstone, Neely, and Boles have written a beautiful survey and performance evaluation of explicit allocators [\[118\]](../../05-appendix-and-references/References.md#ref-118). The general comments in this book about the throughput and utilization of different allocator strategies are paraphrased from their survey. Jones and Lins provide a comprehensive survey of garbage collection [\[56\]](../../05-appendix-and-references/References.md#ref-56). Kernighan and Ritchie [\[61\]](../../05-appendix-and-references/References.md#ref-61) show the complete code for a simple allocator based on an explicit free list with a block size and successor pointer in each free block. The code is interesting in that it uses unions to eliminate a lot of the complicated pointer arithmetic, but at the expense of a linear-time (rather than constant-time) free operation. Doug Lea developed a widely used open-source `malloc` package called `dlmalloc` [\[67\]](../../05-appendix-and-references/References.md#ref-67).
