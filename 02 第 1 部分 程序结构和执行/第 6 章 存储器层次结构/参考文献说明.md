# 参考文献说明

[返回章节目录](./%E7%AC%AC6%E7%AB%A0%20%E5%AD%98%E5%82%A8%E5%99%A8%E5%B1%82%E6%AC%A1%E7%BB%93%E6%9E%84.md)

内存和磁盘技术变化得很快。根据我们的经验，最好的技术信息来源是制造商维护的 Web 页面。像 Micron、Toshiba 和 Samsung 这样的公司，提供了丰富的当前有关内存设备的技术信息。Seagate 和 Western Digital 的页面也提供了类似的有关磁盘的有用信息。

关于电路和逻辑设计的教科书提供了关于内存技术的详细信息\[[58](#ref-58), [89](#ref-89)\]。IEEE Spectrum 出版了一系列有关 DRAM 的综述文章[\[55\]](#ref-55)。计算机体系结构国际会议（ISCA）和高性能计算机体系结构（HPCA）是关于 DRAM 存储性能特性的公共论坛\[[28](#ref-28), [29](#ref-29), [18](#ref-18)\]。

Wilkes 写了第一篇关于高速缓存存储器的论文[\[117\]](#ref-117)。Smith 写了一篇经典的综述[\[104\]](#ref-104)。Przybylski 编写了一本关于高速缓存设计的权威著作[\[86\]](#ref-86)。Hennessy 和 Patterson 提供了对高速缓存设计问题的全面讨论[\[46\]](#ref-46)。Levinthal 写了一篇有关 Intel Core i7 的全面性能指南[\[70\]](#ref-70)。

Stricker 在[\[112\]](#ref-112)中介绍了存储器山的思想，作为对存储器系统的全面描述，并且在后来的工作描述中非正式地提出了术语“存储器山”。编译器研究者通过自动执行我们在[6.6 节](./6.6%20%E7%BB%BC%E5%90%88%EF%BC%9A%E9%AB%98%E9%80%9F%E7%BC%93%E5%AD%98%E5%AF%B9%E7%A8%8B%E5%BA%8F%E6%80%A7%E8%83%BD%E7%9A%84%E5%BD%B1%E5%93%8D.md#6.6%20%E7%BB%BC%E5%90%88%EF%BC%9A%E9%AB%98%E9%80%9F%E7%BC%93%E5%AD%98%E5%AF%B9%E7%A8%8B%E5%BA%8F%E6%80%A7%E8%83%BD%E7%9A%84%E5%BD%B1%E5%93%8D)中讨论过的那些手工代码转换来增加局部性\[[22](#ref-22), [32](#ref-32), [66](#ref-66), [72](#ref-72), [79](#ref-79), [87](#ref-87), [119](#ref-119)\]。Carter 和他的同事们提出了一个高速缓存可知晓的内存控制器（cache-aware memory controller）[\[17\]](#ref-17)。其他的研究者开发出了高速缓存不知晓的（cache-oblivious）算法，它被设计用来在不明确知道底层高速缓存存储器结构的情况下也能运行得很好\[[30](#ref-30), [38](#ref-38), [39](#ref-39), [9](#ref-9)\]。

关于构造和使用磁盘存储设备也有大量的论著。许多存储技术研究者找寻方法，将单个的磁盘集合成更大、更健壮和更安全的存储池\[[20](#ref-20), [40](#ref-40), [41](#ref-41), [83](#ref-83), [121](#ref-121)\]。其他研究者找寻利用高速缓存和局部性来改进磁盘访问性能的方法\[[12](#ref-12), [21](#ref-21)\]。像 Exokernel 这样的系统提供了更多的对磁盘和存储器资源的用户级控制[\[57\]](#ref-57)。像安德鲁文件系统[\[78\]](#ref-78)和 Coda[\[94\]](#ref-94)这样的系统，将存储器层次结构扩展到了计算机网络和移动笔记本电脑。Schindler 和 Ganger 开发了一个有趣的工具，它能自动描述 SCSI 磁盘驱动器的构造和性能[\[95\]](#ref-95)。研究者正在研究构造和使用基于闪存的 SSD 的技术\[[8](#ref-8), [81](#ref-81)\]。
