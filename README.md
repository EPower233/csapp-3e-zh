# 深入理解计算机系统 · CS:APP 3e

《深入理解计算机系统（原书第 3 版）》（*Computer Systems: A Programmer's Perspective, 3e*）中英双语在线阅读版，支持中英分屏对照、全文检索、主题与布局自定义及原生矢量插图。

- **在线阅读**：<https://epower233.github.io/csapp-3e-zh/>
- **English Edition**：<https://epower233.github.io/csapp-3e-zh/en/>

## 阅读特性

- **中英对照阅读**：宽屏下可在章节页开启「中英对照」双栏分屏与同步滚动（中文在左，英文在右），亦可单独切换中文版或英文版。
- **自定义主题与布局**：右上角面板支持切换阅读布局、页面最大宽度、主题色板与聚光灯模式，支持浅色/深色主题。
- **代码、公式与表格**：支持代码高亮、行号与一键复制，完整渲染 LaTeX 数学公式、标准脚注、练习题/答案与参考文献跳转。
- **明暗自适应矢量插图**：中英文全书插图采用原生矢量 SVG，自动适配浅色与深色模式。
